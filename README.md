# YM → SoundCloud Transfer Service

Приложение для быстрого переноса музыкальных плейлистов из **Яндекс Музыки в SoundCloud** по публичной ссылке **без ввода паролей от аккаунтов**.

---

## ✨ Ключевые возможности

1. **Zero-Login импорт:**
   - Чтение публичных плейлистов Яндекс Музыки без авторизации и API-токенов (`music.yandex.ru/users/.../playlists/...` или `/album/...`).
   - Автоматическое извлечение названий, артистов, альбомов и точной длительности треков.

2. **Умный поиск в SoundCloud:**
   - Работа через внутренний публичный API v2 SoundCloud.
   - Очистка метаданных от шума (`(feat. ...)`, `(prod. ...)`, `[Explicit]`, `Remastered`).
   - Двойной запрос (Кириллица + Латинская транслитерация) для нахождения фанатских перезаливов.
   - Сверка по длительности (Fuzzy + Duration Match, допуск ±5–7с): отсеивание 30-секундных сниппетов, ускоренных nightcore-версий и длинных миксов.
   - Асинхронный поиск с умным rate-limiting (параллельные запросы + jitter) для безопасного переноса 100+ треков.

3. **Два режима работы без паролей:**
   - **Режим Zero-Login:** Интерактивный список треков со статусами («Точное совпадение», «Найден перезалив», «Не найден»), прямыми ссылками на SoundCloud, возможностью выбрать другой вариант из топ-3 и экспортом (M3U, JSON, ссылки).
   - **Авто-сборка в профиль SoundCloud:** Достаточно вставить `oauth_token` из активной сессии браузера (в интерфейсе есть визуальная подсказка в 2 клика через DevTools Cookies) — приложение само создаст плейлист в аккаунте и добавит туда все найденные треки.

4. **Дизайн Soft White / Soft Black:**
   - Ультра-минималистичный адаптивный интерфейс с чистыми линиями и поддержкой светлой и тёмной тем.

## 🚀 Быстрый запуск (1 команда)

В терминале перейдите в папку проекта и запустите:

```bash
cd /Users/egor/.gemini/antigravity/scratch/ym-to-soundcloud
./run.sh
```

Скрипт автоматически:
1. Создаст виртуальное окружение `.venv` (если его нет).
2. Установит необходимые зависимости (`fastapi`, `uvicorn`, `httpx`, `rapidfuzz`).
3. Запустит локальный сервер на `http://localhost:8000`.
4. Автоматически откроет браузер с веб-интерфейсом.

### Ручной запуск (альтернатива):
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn backend.app:app --host 127.0.0.1 --port 8000 --reload
```
Затем откройте в браузере: `http://localhost:8000`.
